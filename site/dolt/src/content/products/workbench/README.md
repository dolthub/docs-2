# Dolt Workbench

![](../../.gitbook/assets/dolt-workbench-preview.png)

The [Dolt Workbench](https://github.com/dolthub/dolt-workbench) is a modern, open source SQL workbench for your MySQL and PostgreSQL compatible databases. Use [Dolt](https://doltdb.com) or [Doltgres](https://github.com/dolthub/doltgresql) to unlock powerful version control features.

The Dolt Workbench is available via the [Mac](https://apps.apple.com/us/app/dolt-workbench/id6720702995?mt=12) or [Windows](https://apps.microsoft.com/detail/9nq8lqph9vvh?hl=en-us&gl=US) App stores.

See the [Dolt Workbench README](https://github.com/dolthub/dolt-workbench/blob/main/) on GitHub for more information.
