* Fixes SMTP connection bug in `doltlabapi` and `smtp_connection_helper` that prevented insecure TLS STARTTLS connections.
* Fixes ignored custom default user bug.
* Fixes ignored `doltlabdb.root_volume_path` bug.
* Bump version of Dolt in Jobs to v1.59.20.
