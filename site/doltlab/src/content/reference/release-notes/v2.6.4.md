## DoltLab Features/Bug Fixes

* Bump Dolt version in Jobs to v2.7.2.
* Add support for Doltgres databases.
* Add support for DoltLite databases.
  * DoltLite clients connect to DoltLab on port `50052`, which must now [allow ingress `TCP` connections](/guides/installation#networking-requirements).
* Fix a remote API authorization issue. We recommend that all users upgrade.
* Show an error when OIDC login state does not match, instead of loading indefinitely.
* Update Envoy to v1.38.1.
