---
title: System Catalog Schema
---

The [Postgres `pg_catalog` schema](https://www.postgresql.org/docs/15/catalogs.html)
provides access to a variety of database metadata useful for inspecting your database and
also used by database tooling. Doltgres provides a subset of the data available in
`pg_catalog`, as described below. In general, all tables from Postgres's `pg_catalog`
exist, with the correct schema, but not all data is populated. The "Populated" column
below indicates whether Doltgres returns data for each table or view: ✅ means fully
populated, 🟠 means partially populated, and ❌ means the table exists with the correct
schema but returns no rows. If you need support for `pg_catalog` metadata that is
available in Postgres, but not yet available in Doltgres, please
[open a GitHub issue](https://github.com/dolthub/doltgresql/issues) to let us know
what you need.
